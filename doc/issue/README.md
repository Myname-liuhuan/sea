# Issue 生成规范

## 核心字段

| 字段 | 说明 |
|------|------|
| 问题标题 | 一行描述问题，简洁明了 |
| 问题时间 | 记录遇到时间，方便搜索 |
| 问题描述 | 场景、触发条件、报错信息 |
| 问题示例代码 | 可复现代码或请求示例 |
| 修改方案 / 解决方法 | 最终解决方案 + 尝试过的其他方案 |
| 问题原理 / 分析 | 为什么出现问题，方便复盘 |
| 经验或注意事项 | 类似问题可能踩的坑 |

## 可选增强

1. **标签/分类**  
   ```markdown
   Tags: Spring Boot, Nginx, HTTP, Multipart
   ```

2. **相关文件**  
   ```markdown
   相关文件: [模块]/[文件名]:[行号]  # 示例: sea-media/VideoController.java:59
   ```

3. **参考资料**  
   ```markdown
   参考资料: [RFC 5987](https://tools.ietf.org/html/rfc5987)
   ```

## 文件命名

```
doc/issue/年月/年月日_issue内容.md
```

示例：`doc/issue/202602/20260212_HTTP响应头中文文件名编码错误.md`

## 模板示例

```markdown
# [问题标题]

## 问题时间
[YYYY-MM-DD]

## 问题描述
- 场景: [描述场景]
- 触发条件: [触发条件]
- 报错信息: [报错信息]

## 问题示例代码
\```[语言]
[代码片段]
\```

## 修改方案 / 解决方法
### 最终解决方案
\```[语言]
[修复代码]
\```

### 其他尝试过的方案
1. [方案描述]: [问题]

## 问题原理 / 分析
[技术分析]

## 经验或注意事项
[经验总结]
```
